### 1. 丝滑来自持续重算的多层折叠场

原版不是视频、图片平移、一个渐变带，也不是流体物理模拟。每个像素从归一化坐标出发，在约 70–95 次循环里依次进行：

- 横纵两个方向的正弦扰动，且后一步依赖已更新的坐标；
- 旋转与剪切组成的线性变换；
- 轻微缩放；
- 在变换后的坐标上计算狭长椭圆形发光分布，并衰减远处能量；
- 将本层颜色和亮度累加到该像素。

单次变形很小，但经过几十层，局部颜色会延伸、汇聚、分叉、折返，形成层叠的薄丝带。时间驱动每层扭曲，另有双频呼吸改变缩放和偏移。它的“流动”是整片空间映射持续改变，不是整张画面挪动一点。

关键参数包含 theta、shear、shrink、layers、warp frequencies/amplitudes、aspect、offset、centre、zoom、flow speed/direction、breathing 和 echo 等，共 34 个基础参数。线性变换接近保持面积；细小的系数变化经过几十次迭代会产生很大的构图差异。因此随便堆噪声或加大平移速度不等价。

### 2. 多颜色来自连续色相生成，不等于原站已经提供任意多色输入界面

已读代码用 OKLCH 的亮度、色度、基准色相、色相跨度与颜色周期生成色彩。每层颜色同时取决于层编号、时间和空间距离。同一画面中的粉、橙、紫、蓝、青可以来自一条连续色相轨迹，而不需要对应数量的颜色选择器。

所以可以确认“算法支持多色变化”；不能仅凭截图断言“原站 UI 支持用户输入很多独立颜色”。为了满足用户的创作需求，本地版明确提供 **2–8 个可增删、可输入 HEX 的色标**，在 OKLab 中平滑插值，按空间、层次与时间取色。OKLab 和 OKLCH 是同一感知色彩模型的不同坐标表达，但本地的多色标插值并不等于原版的色相跨度算法。

标准参考：[W3C CSS Color 4](https://www.w3.org/TR/css-color-4/#color-conversion-code)。本地使用标准数学变换，没有引入第三方颜色库。

### 3. 背景主题与后处理是独立环节

原版先将累加的光场做 ACES 曲线映射和各通道调整，然后分别合成深底/浅底。浅色模式不是简单反相。

用户名另有独立的纹理分配：none、dither、grain、ascii、wave、sparkle、pixel、halftone、prism。截图中的橙色点阵和粉色像素块属于后处理，不能都当作飘动粒子。

本地版实现光滑、颗粒、像素、网点、抖色，并保留独立粒子层。尚未实现原版 ASCII、棱镜以及完全相同的波浪后处理。

### 4. 随机不是毫无约束地填参数

原版把用户名转小写后生成确定性随机序列，在有限范围内取参数；它还会用低分辨率 CPU 采样评估亮区覆盖率、平均亮度和过曝比例，不合格时重试，最多尝试 16 组。纹理类型使用另一条随机序列。

因此“种子稳定”只是基础，控制参数分布和过滤低质量构图也影响最终观感。本地使用受约束参数范围，尚未实现原版那套 CPU 质量筛选；不声称随机结果与用户名原作一致。

### 5. 性能也影响丝滑

原版存在降低场分辨率、浮点离屏纹理、Catmull–Rom 重建和细微抖色的路径，以减少昂贵迭代计算。不能简单认为高分辨率画布必然更清晰或更流畅。

本地改为两阶段渲染：折叠场限制在最多 850×650 的比例内，再在线性采样重建后的全尺寸画面上做后处理及粒子。不同设备表现会不同。本地现已支持半浮点纹理（不支持时回退 RGBA8）与三次 B 样条重建。B 样条权重非负，可避免浅色运动边缘的过冲；与原版 Catmull–Rom 的重建核不同。

## 前两版为什么差得大

- 第一版：少量等值线、噪声和加法发光，形成霓虹线条，缺少原版多层折叠的面状颜色。
- 第二版：仅凭一帧简化为一条柔边色带，移除了细线，也移除了关键的多层空间结构。
- 第二版默认运动速度 0.35，再乘着色器中的 0.24，实际时间变化只有 0.084 倍，位移幅度也很小；看起来几乎不动是实现问题。
- 固定两种主体颜色无法表达多层多色交织。

## 本地当前实现边界

当前源码独立编写，采用同类数学结构：46–82 层递归扭曲/折叠、连续时间驱动、轻微呼吸、每层采样多色标、覆盖率合成、独立后处理。默认速度 1，折叠相位每秒变化 0.65；速度 0 会冻结形态、颜色、纹理和粒子。

它不是原站代码的逐行移植，也不是原站算法和审美分布的完全复刻。默认参数、颜色采样、合成曲线、重建方式和随机采样策略均有差异。原站公开脚本的授权尚未确认，因此没有将那些文件纳入项目，也没有把它们标为本项目 MIT。

## 验证

`npm test` 检查种子可复现、多色色标锁定、导入校验、旧格式迁移、OKLab 往返误差和色标端点。

`/tests/render.html` 在实际 WebGL 中比较 t=0、t=1/60、t=2 的像素差，检查连续运动、相邻帧变化幅度、同一时间精确复现、颜色/粒子/纹理生效和六类形态可渲染。帧间差异能发现静止或明显跳变，不等价于完整的视觉质量评估。

## 后续：运动边缘出现分层细线

旧实现将每层 Lorentzian 分布平方收窄，Fold 模式还按层编号调制亮度，这会暴露离散层边缘。已改为较宽的重叠分布、去掉层间亮度调制、淡出末尾层，并补充高精度中间纹理和 B 样条重建。固定测试用例 aurora / Fold / detail 5.48 / softness 0.74 在 0、2、4 秒的前后对比中，抑制一位抖色噪声后的空间高通能量分别下降约 66%、50%、52%。这是该测试用例的指标，不代表所有种子都不存在细线。

## 截图对齐：主体向背景延伸的渐变

依据用户 02:45 的截图作视觉推断：背景的染色与主体相连，越靠近色带越浓。这并不证明原站采用独立的多层模糊。本地为达到这种观感，自行设计了三个同源、不同宽度的连续分布：浓色主体、邻近过渡、宽范围背景。每一次折叠共享坐标、时间和调色板样本，分别累积颜色和覆盖率，再从外向内合成，背景会随主体一起形变。

`backgroundTint` 控制两层外延染色的量，`backgroundSpread` 控制外延范围；设染色为 0 时，扩散参数不影响输出。`softness` 只改变汇总后主体密度的响应曲线，不改变场的半径，避免柔度一高整体就糊成色雾。所有层先连续叠加，保留之前末尾淡出和高精度重建，避免逐层描边。

增加水平、垂直构图偏移以支持近景裁切；“粉霞 · 参考构图”是一组原创参数研究，并非原作品的种子/代码。三层合成是本地的设计选择，不声称是原站确切实现。GPU 检查新增背景关闭、范围独立性、同色染色方向与粉霞运动检查；旧参数文件补默认值。

## 色带景深：中心贴近毛玻璃，两侧后退

按用户的进一步说明，已移除按正弦区域划分清晰区的方案。以色带自身累计几何密度建立浅层高度近似：色带脊线距离玻璃最小，两侧距离逐渐增大。将距离写入离屏纹理的 alpha 通道；后处理使用该距离同时控制模糊半径与清晰过渡。它独立于调色板、色彩浓度和背景扩散，随色带形变而变，未建立真实三维几何或物理玻璃模型。开关关闭时均匀模糊，强度归零完全旁路。原有参数文件沿用区域开关字段，无需重新导入。

## 新增非回旋运动

新增交叉穿行、波浪推进、编织穿梭、三路汇流，独立于旧递归旋转场。分别计算两条斜向正弦路径、三条错相平行波、两条反相编织波、三路不同方向的曲线路径。每条路径由连续重叠的宽色层组成，色带长度有限，背景和景深继续从同一几何场派生。关闭颜色流动时形状仍持续变化。

主体大小和中心偏移独立：先从画面坐标减去中心偏移，再绕该中心缩放与旋转。旧参数的偏移不再乘以缩放，因此非零偏移的老构图位置会改变；旧模式和配色均保留。所有模式参与解锁后的随机生成与导入校验。

## 合并形态，重做共同流场

用户反馈固定宽度的交叉/波浪路径像塑料条，因此该实现已被替换，前六种相近折叠模式也合并为一个丝绸入口。当前只保留四类：丝绸流动、交汇融流、双涡卷流、层流漫涌。

新三类采用共享材料坐标映射：连续剪切与局部旋转组合，使整片染料的边界和内部颜色共同拉伸、卷入、变宽或收窄。多组宽而软的染料体在同一流场中合成，删除每条正弦中心线独立运动的结构。压缩试验中出现过细的条纹，最终采用五级适度形变并加宽初始染料体。此为确定性的程序化流动视觉，不是求解压力/速度的物理流体模拟。

参数版本升级为 3，旧文件自动映射形态并保留其余设置。运动连续性、几何独立于颜色变化、大小与位移独立均通过 GPU 检查；这些检查只保证行为，观感仍须结合动态预览判断。

## 层流漫涌的开场与方向变化

仅调整 Drift：移除三个平行、同朝向的染料长片，改为由种子决定方向和位置的宽色片；五级局部剪切各有不同的斜向坐标，方向以多个连续时间频率缓慢变化，再叠加不同中心的局部卷曲。开场使用已经变形的相位，无需等待从直条过渡。随机性来自种子，不逐帧抽样，因此仍可复现且无随机跳帧。其他三种模式的公式未改。

新增四组种子的开场半秒变化、相邻帧连续性、后续持续运动和不同种子初始形变检查。全部 46 项 GPU 检查通过。
